# Prime Divisor Counter

A Python program that reads 10 integers and finds the number with the highest count of distinct prime divisors.

If multiple numbers have the same number of prime divisors, the largest number is selected.

---

## Features

- Reads 10 integers from user input
- Counts distinct prime divisors
- Finds the number with the maximum count
- Tie-breaking using the larger number

---

## Example

### Input

```text
123
43
54
12
76
84
98
678
543
231
```

### Output

```text
678 3
```

---

## How to Run

```bash
python main.py
```
