# Bingo Game (OOP)

A simple Bingo / Number Guessing game written in Python using Object-Oriented Programming (OOP).

## Features

- Multiple players
- Random number generation
- Limited guesses
- Winner detection
- Input validation
- OOP design

## Concepts Used

- Classes & Objects
- Encapsulation
- Class Methods
- Loops & Conditions
- Random Module
- Exception Handling

##Commands

While running the program, you can use the following commands:
- add → Add a new player
- start → Start the game
- exit → Exit the application

## How to Run

- Add one or more players using add
- Start the game using start
- Each player tries to guess a number between 0 and 10
- The game gives hints (higher / lower)
- First correct guess wins the game
- Each player has only 3 attempts

## Example Gameplay

- What do you want to do?
Order: add

Enter your name: Amin

Order: start

Amin, please enter your guess: 5
Choose higher number
2 guesses left

Amin, please enter your guess: 8
Bingo!
